A1+ Kapitel 7：第三格、方位介词与静三动四、情态动词 dürfen、比较级

🧩 第三格名词组 (Die Nomengruppe im Dativ)

💡 核心规则：在第三格中，阳性和中性冠词变为 dem / einem，阴性变为 der / einer，复数变为 den 且复数名词词尾加 -n。形容词在第三格中永远以 -en 结尾。

格 (Kasus) feminin (阴性) maskulin (阳性) neutrum （中性） Plural （复数）
Nominativ / Akkusativ die Wand der / den Tisch das Sofa die Stühle
Dativ (第三格) der / einer / weißen dem / einem / großen dem / neuen den großen

🗺️ 方位介词与“静三动四”原则

📍 核心区分规则：

  • 📍 静态 “在哪儿” (wo)： 表示静止的状态或位置（常配静态动词如 liegen, stehen），使用方位介词 + 第三格 (Dativ)。
  • 🏃 动态 “到哪儿” (wohin)： 表示动作的方向或去向（常配动态动词如 legen, stellen），使用方位介词 + 第四格 (Akkusativ)。
  • “静三动四”双向介词： in, auf, an, über, neben, unter, zwischen, hinter, vor。

✍️ 随堂互动练习：静三动四实战

💡 请判断句子的动作是“静态(wo)”还是“动态(wohin)”，并填入正确的定冠词 (der/den/dem/die/das)：

  • 1. 📍 (wo) Das Bild hängt an (die) Wand. (画挂在墙上 - 静态)
  • 2. 🏃 (wohin) Ich hänge das Bild an (die) Wand. (我把画挂到墙上 - 动态)
  • 3. 📍 (wo) Das Buch liegt auf (der) Tisch. (书平放在桌子上 - 静态)
  • 4. 🏃 (wohin) Ich lege das Buch auf (der) Tisch. (我把书放到桌子上 - 动态)

🧩 情态动词 dürfen (允许/可以)

  • nicht dürfen： 表示禁止（不准、不允许）。
  • 礼貌请求： 用于委婉地询问Darf ich ... ... “我可以……吗？”。

📈 形容词比较级 (Komparation der Adjektive)

💡 核心规则：
- 修饰名词时： 比较级形式先加 -er，再根据其在句中的性、数、格添加相应的形容词词尾。
- 表语或其他情况： 基本形式为 形容词比较级 (-er) + als + 被比较对象。

📌 变形与特殊规则 (点击阴影查看)：

  • 变音规则 (a/o/u 变为 ä/ö/ü)： warm ➡️ wärmer / groß ➡️ größer / jung ➡️ jünger
  • 带 -er 词尾的形容词： teuer ➡️ teurer (去掉中间的 e 再加 -er)
  • 特殊不规则变化： gut ➡️ besser / viel ➡️ mehr / gern ➡️ lieber

📜 房屋规章 (Hausordnung) —— 点击阴影自测填空：

  • 夜间安静：Alle Mieter müssen die Nachtruhe respektieren. (所有租户必须遵守夜间休息时间。)
  • 禁止噪音：Man darf in der Wohnung und im Haus keinen Lärm machen. (人们不准在公寓和房子里制造噪音。)
