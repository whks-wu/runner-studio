🧩 情态动词 können 与框形结构

⚠️ 语法规则：情态动词 + 动词原形。情态动词在第二位，动词原形在句末

können 的核心含义： 1. 能力 ； 2. 可能性

💡 互动填空：请填写 können 的现在时变位（提示：kann, kannst, kann, können, könnt, können）

人称 (Person)können 变位
ich
du

wir
ihr
sie / Sie

💡 经典例句解析

  • 👉 表示“能力”：
    Ich kann Deutsch. (我会德语。)
  • 👉 表示“可能性”（完美展示框形结构）：
    Sie kann morgen mich besuchen. (她明天可能会拜访我。)

2. 工作场所与部门功能 (Am Arbeitsplatz & Abteilungen) —— 点击阴影查看

  • 办公室评价：Das ist ein schönes Büro. (这是一个漂亮的办公室。)
  • 设备故障：Der Drucker ist kaputt. (打印机坏了。)
  • 机器不工作：Die Kaffeemaschine funktioniert / geht nicht. (咖啡机不工作了。)
  • 物品价格：Das ist teuer! (这太贵了！)
  • 🏢 行政部 (die Verwaltung)：Hier kann man Rechnungen bezahlen.(在这里可以支付账单。)
  • ☕ 食堂 (die Kantine / die Mensa)：Hier kann man etwas essen.(在这里可以吃东西。)
  • ℹ️ 秘书处 (das Sekretariat)：Hier kann man Informationen bekommen.(在这里可以获取信息。)
  • 🗣️ 语言中心 (das Sprachenzentrum)：Hier kann man Sprachkurse besuchen.(在这里可以参加语言课程。)

3. 业余时间与爱好 (Freizeit) —— 点击阴影查看

  • 询问看法：Wie finden Sie Marburg? (您觉得马尔堡怎么样？)
  • 周末安排：Was machen Sie am Wochenende? (您周末做什么？)
  • 乐器爱好：Welches Instrument spielen Sie? (您弹奏什么乐器？)
  • 表达不会：Ich kann leider nicht gut Salsa tanzen. (很遗憾，我萨尔萨舞跳得不好。)
  • 表达不会：Ich kann leider kein Instrument spielen. (很遗憾，我不会演奏任何乐器。)

4. 核心动词搭配提炼 (Wichtige Verben)

  • 🏍️ 骑摩托车：Motorrad fahren
  • 🧘‍♀️ 做瑜伽：Yoga machen
  • 🌐 网上冲浪：im Internet surfen
  • ❓ 缺少某物：Es fehlt etwas.
  • 🏢 静态放置：Im Büro steht ein Schreibtisch. (办公室里放着一张写字台。)
